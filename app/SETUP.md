# 信じてMe!（約束の担保）― 動かし方

Kotlin Multiplatform ＋ Compose Multiplatform で作った、Android / iOS 共通のプロトタイプです。
画面のコードは `composeApp/src/commonMain` に1つだけあり、両方の OS で同じものが動きます。

## 必要なもの

| 対象 | 必要なもの |
|------|-----------|
| Android | Android Studio（最新版）、JDK 17 以上 |
| iOS | **Mac** ＋ Xcode（iOS のビルドは Mac でしかできません） |

あわせて、Android Studio に **Kotlin Multiplatform プラグイン** を入れておくと便利です。

## Android で動かす

1. Android Studio で `app` フォルダを開く
2. Gradle の同期が終わるまで待つ（初回はライブラリのダウンロードがあります）
3. 実行構成で `composeApp` を選んで、エミュレータか実機で実行

## iOS で動かす

このフォルダには Xcode プロジェクト（`iosApp`）が入っていません。Xcode のプロジェクトファイルは手書きすると壊れやすいので、公式のテンプレートから持ってきます。

1. https://kmp.jetbrains.com を開き、次の設定でプロジェクトを作ってダウンロードする
   - Project Name：`Shichiire`
   - Project ID：`com.example.shichiire`
   - Android と iOS にチェック、iOS は **Share UI（Compose Multiplatform）**
2. ダウンロードしたプロジェクトの `iosApp` フォルダを、この `app` フォルダの中にコピーする
3. `iosApp/iosApp.xcodeproj` を Xcode で開いて実行する
   - 共有コードの `MainViewController()` を呼ぶ形はテンプレートと同じなので、Swift 側の変更はいりません
   - 実機で動かすときは、`iosApp/Configuration/Config.xcconfig` の `TEAM_ID` に自分のチーム ID を入れる

Android Studio に Kotlin Multiplatform プラグインが入っていれば、実行構成で `iosApp` を選んで Android Studio から起動することもできます。

## うまくいかないとき

- **Gradle の同期でバージョンのエラーが出る**
  `gradle/libs.versions.toml` のバージョン（Kotlin 2.1.21 / Compose Multiplatform 1.8.2 / AGP 8.7.3）を、手元の Android Studio やテンプレートが提示するバージョンに合わせてください。
- **iOS で `ComposeApp` が見つからない**
  一度 Android Studio で Gradle を同期してから、Xcode でもう一度ビルドしてください。

## プロトタイプとしての割り切り

- 起動すると接続画面が出ます。「2台で同期する」か「1台で使う（オフライン）」を選びます
- 1台モード：データはメモリ上だけです。アプリを終了すると、最初のサンプル5件に戻ります。端末を手渡しして「自分 → 相手」の順に申告します（相手も担保を出す約束では、先に相手が担保を書きます）
- 2台モード：データは中継サーバーのメモリ上にあり、サーバーを止めると消えます（くわしくは下の「2台で同期してデモする」）
- 期限は候補チップから選びます。デモ用に「1分後」があります

## デモの流れ（1台モード・予備）

2台がつながらないときの予備です。接続画面で「1台で使う（オフライン）」を選びます。

1. 一覧で信頼残高（50%）と5件の約束を見せる
2. 「破った」の約束（ジム）を開く → 担保が公開されている
3. 「＋ 新しい約束」→ 担保を入力（プレビューで見え方を確認）→ 期限「1分後」→ 封をする
4. 封をした封筒を見せる。担保は本人にも見えない
5. 約束した人が「守った／破った」を申告 →「相手に端末を渡してください」→ 客席の人に渡して申告してもらう
6. 担保を出した人ごとに、一致すれば燃える／封が開く。食い違えば「不一致」
7. 一覧に戻って、信頼残高が変わっていることを見せる

## 2台で同期してデモする

2台のスマホが、同じWi-FiにあるPCの「中継サーバー」を通して約束を同期します。
約束した人と相手がそれぞれの端末で、担保を出した人ごとに「守った／破った」を申告し、**2人の答えがそろうと**結果が決まります。結果は人ごとで、一致すればその人の担保が燃える／開く、一致しなければ「不一致」になり、その人の担保は永久に封印。

### 準備（本番前に1回通しておく）

1. PCとスマホ2台を**同じWi-Fi**につなぐ
   - 会場のWi-Fiは端末どうしの通信を禁止していることがあります。その場合は、スマホのテザリングにPCともう1台をつなぐと確実です
2. PCで中継サーバーを起動する（`app` フォルダで実行）

   ```bash
   ./gradlew :server:run
   ```

   起動すると `192.168.x.x:8787` のようなアドレスが表示されます
   - Mac で macOS のファイアウォールを有効にしている場合、Java の受信接続を許可してください
3. 両方のスマホでアプリを開き、「2台で同期する」で
   - **あなたの名前**：Aの端末は「けんた」、Bの端末は「たけし」のように**別の名前**
   - **サーバーのアドレス**：手順2で表示されたもの（ポートを省くと 8787）
4. 「つなぐ」

### 当日の流れ（約3分）

1. Aの端末：「＋ 新しい約束」→ 相手に **Bの端末で入れた名前** を書く → 期限「1分後（デモ用）」→ 担保を出す人を選ぶ（デモでは「2人とも」がおすすめ）→ 自分も担保を出すなら担保を書いて「封をする」（「相手だけ」なら「約束を送る」）
2. Bの端末：1秒ほどで「けんたさんから」の約束として届く。担保は見えない。「2人とも」「相手だけ」なら、Bも担保を書いて封をする
3. 期限が来たら（期限前でも可）、AとBがそれぞれ申告する。相手の答えは結果が出るまで見えない
4. それぞれの画面が1〜2秒ほどで結果に切り替わる。「2人とも」で片方だけ「破った」にすると、破った人の担保だけが開く（デモの見せ場）
5. 一覧の信頼残高を見せる（不一致は別に数える）

### Mac のエミュレータ2台で試すとき

エミュレータの標準の通り道（`10.0.2.2`）は、Mac が混んでいると1回の通信に1秒近くかかったり、途中で止まったりします。adb のトンネルを使うと速く安定します。

1. エミュレータを2台起動したあと、それぞれで次を実行する（エミュレータを起動し直したらもう一度）

   ```bash
   adb -s emulator-5554 reverse tcp:8787 tcp:8787
   ```

   ```bash
   adb -s emulator-5556 reverse tcp:8787 tcp:8787
   ```

2. アプリの「サーバーのアドレス」には `127.0.0.1` と入れる

### iOS で同期モードを使うとき

`iosApp` の `Info.plist` に次を足してください（http で同じWi-Fiの PC につなぐため）。

```xml
<key>NSLocalNetworkUsageDescription</key>
<string>同じWi-Fiの中継サーバーと約束を同期するために使います。</string>
<key>NSAppTransportSecurity</key>
<dict>
    <key>NSAllowsArbitraryLoads</key>
    <true/>
</dict>
```

初回接続時に「ローカルネットワークへのアクセス」を聞かれたら**許可**してください。拒否した場合は、iOS の設定 → プライバシー → ローカルネットワーク でオンにします。

### 割り切り（デモ用）

- 本人確認は「名前」だけです。同じ名前で別の端末からつなぐと、その人として操作できてしまいます
- 通信は暗号化していない http です。デモ以外のネットワークでは使わないでください
- 「サーバーの約束を全部消す」は、つながっている全員の約束を消します（リハーサル用）
- サーバーを止めると約束は消えます
- 万一つながらないときは、接続画面の「1台で使う（オフライン）」に切り替えれば、端末を手渡しする形でデモを続けられます
